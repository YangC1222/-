# 弈间 · 19×19 五子棋

一个无需构建、可直接部署到 GitHub Pages 的中文五子棋网页。

**在线体验：[https://yangc1222.github.io/-/](https://yangc1222.github.io/-/)**

## 功能

- **19×19 自由五子棋**：黑棋先行，横、竖、斜向连续五子或以上获胜，无禁手；满盘无胜者为和棋。
- **人机对弈**：可以执黑或执白，轻松、标准、挑战三档搜索强度。
- **同屏双人**：两人轮流操作同一棋盘。
- **远程联机 PK**：创建房间后分享邀请链接，好友打开即可加入。房主执黑，好友执白。
- **实时 AI 局势分析**：预估双方胜率、黑棋走势、三个推荐落点和搜索信息；计算在 Web Worker 中进行。
- **悔棋**：人机模式退回你上一次落子前；同屏模式每次退一手；联机需对手同意，退回申请者上一次落子前。
- **认输、再来一局**：联机同步结果，重新开局也需要双方同意。
- **自动保存与棋谱导出**：本地对局保存在浏览器，可导出中文 TXT 棋谱。联机局保持在房主的页面中。
- **手机适配与键盘操作**：方向键选择交点，回车或空格落子。

## 邀请好友远程对弈

1. 打开网页，点击 **邀请好友 → 创建邀请房间**。
2. 等待生成链接，点击 **复制**，通过你常用的聊天工具发给好友。
3. 好友打开链接，自动加入房间；也可以在“邀请好友”中粘贴链接加入。
4. 双方点击 **返回棋盘** 开始对弈。落子、胜负、认输实时同步。
5. 悔棋和“再来一局”需要对方同意，申请期间暂停落子；30 秒未处理会恢复棋局。

联机使用 [PeerJS](https://peerjs.com/client/getting-started) 的公共信令服务建立 WebRTC 数据连接；浏览器库已随源码打包，无需运行自己的后台。网络需要能够访问该服务，公共服务不提供本项目的可用性保证，受限网络下可能需要重试或切换网络。

**双方必须保持页面打开。** 好友刷新后可以通过原链接重连，房主会恢复当前棋局；房主刷新或关闭页面会关闭房间，需要创建新邀请。第三位玩家不能进入已经占用的对局。断线时暂停落子，避免双方棋盘发生分歧。

## AI 分析的含义

AI 使用四方向连子与断点威胁评估、候选点排序、迭代加深的 Negamax / Alpha-Beta 搜索。优先寻找直接连五和防守对方的一步连五，有限搜索时间分别约为 250 / 750 / 1600 毫秒。

**胜率是局势评分的映射，未经实战数据校准。** 它不是专业神经网络棋力、赛事统计或胜负保证。分析中会保留上一次的百分比并明确标记，避免把未完成的分析当作当前结果。已经判定胜负的棋局显示真实的 100% / 0%，和棋显示 50% / 50%。

## 本地运行

安装 Node.js 20 或以上，在项目目录运行：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。应用无运行时安装依赖；不要直接双击 HTML，模块与 Web Worker 需要 HTTP(S) 环境。

规则、AI 战术和联机协议检查：

```sh
npm test
```

可选浏览器检查位于 `tests/browser.mjs`，需要开发机安装 Playwright 与 Chromium/Edge，并先启动网页。设置 `GOMOKU_ONLINE_TEST=1` 会通过真实公共信令服务运行双页面 WebRTC 联机检查。

## 部署

上传源码到 GitHub 后，在仓库 **Settings → Pages** 中选择 `main` 分支的根目录 `/`，即可部署。所有网页资源使用相对路径，支持 `/-/` 等项目路径。

`vendor/peerjs.min.js` 固定使用 PeerJS 1.5.5，保留其 MIT 许可证 `vendor/peerjs-LICENSE.txt`。如需重新下载固定版本，可以运行 `node scripts/vendor-peerjs.mjs`。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` / `styles.css` | 中文界面和响应式布局 |
| `src/game.js` | 落子、连五、悔棋、认输和存档校验 |
| `src/ai.js` / `src/ai-worker.js` | 本地 AI 搜索与后台分析 |
| `src/online.js` | 房间连接、回合校验、操作同步和双方审批 |
| `src/app.js` | 棋盘交互、分析展示、存档和分享链接 |
| `tests/` | 规则、战术、协议与浏览器检查 |
